# AVIATOR AI LAB

An Android educational companion for learning probability and statistics from manually entered sample data.

## Features
- Record manually entered sample values.
- Calculate count, average, median, minimum, maximum, and standard deviation.
- Group sample values into simple ranges.
- Build a debug APK automatically with GitHub Actions.

## Important
This is an educational statistics tool. It does not predict future game results, connect to betting platforms, or provide betting recommendations. Past observations cannot reliably determine a future random outcome.

## Build
Push to the `main` branch or manually run **Build Android APK** in the Actions tab. Download the APK from the workflow run's Artifacts section.
